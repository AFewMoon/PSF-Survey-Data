# 第 8 章 数据可视化实战

> 目标：精读 `plot_survey.py` 的三个绘图函数——100% 堆叠柱、跨年分组水平条形、交叉热力图，以及贯穿所有图表的脚注规范。图不是数据的装饰，而是**口径的声明**。

## 8.1 图表选型：三种图各回答一类问题

| 图型 | 函数 | 回答的问题 | 适用场景 |
|---|---|---|---|
| 100% 堆叠柱 | `plot_stacked` | **结构**：构成比例如何随年变化（类别 ≤ 5） | 单选题（主语言、用途三档、年限分布） |
| 跨年分组条形 | `plot_grouped_hbar` | **比较**：多个选项的量级与各自趋势（选项多） | 多选组 Top N（框架、数据库、IDE）、Top 8 用途 |
| 交叉热力图 | `plot_heatmap` | **关联**：两个分类变量的组合分布 | 年限 × 用途 |

选型原则：**类别少、构成互补 → 堆叠；类别多、各自独立 → 分组条形；两个分类变量 → 热力图**。堆叠图超过 5 个段可读性崩塌（图例与颜色对应困难），这正是多选 Top 10 用分组条形而非堆叠的原因。

## 8.2 100% 堆叠柱：结构比较

```python
def plot_stacked(tab: pd.DataFrame, n_by_year: pd.Series, miss_by_year: pd.Series,
                 title: str, ylabel: str, fname: str, extra_note: str = "",
                 order: list[str] | None = None) -> None:
    """按年份的 100% 堆叠柱状图，段内标注百分比（>=4% 才标注）。"""
    cats = order if order is not None else list(tab.columns)
    tab = tab.reindex(columns=cats, fill_value=0.0)
    fig, ax = plt.subplots(figsize=(10.5, 6.5))
    x = [str(y) for y in tab.index]
    bottom = np.zeros(len(tab))
    for i, cat in enumerate(cats):
        vals = tab[cat].to_numpy(dtype=float)
        ax.bar(x, vals, bottom=bottom, color=PALETTE[i % len(PALETTE)],
               label=cat, edgecolor="white", width=0.62)
        for j, (b, v) in enumerate(zip(bottom, vals)):
            if v >= 4.0:
                ax.text(j, b + v / 2, f"{v:.1f}%", ha="center", va="center",
                        fontsize=9, color="white", fontweight="bold")
        bottom += vals
    ax.set_ylim(0, 100)
    ...
```

设计要点：

- **`order` 参数与有序轴**：堆叠顺序是图的可读性核心——三档用途图强制 "工作 → 兼顾 → 个人" 的语义顺序，而不是数据列序。调用方（`chart_01`/`chart_02`）显式传 `order`。
- **`bottom` 累加实现堆叠**：matplotlib 没有原生堆叠柱参数，逐层 `bottom=bottom` 再累加。`edgecolor="white"` 给段间留白色细边——100% 堆叠图相邻段同色系时，细边是区分边界最廉价有效的一招。
- **`v >= 4.0` 才标注**：小于 4% 的段放不下 `9pt` 白字，硬放会溢出/重叠。**省略标注 ≠ 省略数据**（段还在图上），但读者读不到小段数字——这就是为什么堆叠图只适合 ≤ 5 个类别：小类别信息丢失在视觉上。图例（右侧 `bbox_to_anchor=(1.01, 0.5)`）承担"什么颜色是什么"的职责，让绘图区保持干净。
- **`PALETTE` 六色循环**：六份年度数据固定六色（蓝橙绿红紫棕，seaborn deep 前 6 色）。跨图保持"同年同色"是图例系统的隐性契约（`plot_grouped_hbar` 按年份取色）。加第七年时色板会绕回第一色——届时要么换 qualitative 色板，要么改用"年份做色阶"的方案。

`ylabel="受访者占比（%）"` 与 `ylim(0,100)` 显式声明"这是构成占比"，防止读者把堆叠高度误读为绝对人数。

## 8.3 跨年分组水平条形：多选项比较

```python
def plot_grouped_hbar(rates: pd.DataFrame, counts: pd.DataFrame | None,
                      options: list[str], n_by_year: pd.Series, miss_by_year: pd.Series,
                      title: str, xlabel: str, fname: str, extra_note: str = "",
                      labels: list[str] | None = None) -> None:
    """跨年分组水平条形图：每选项 6 个年份条，标注百分比（及人数）。"""
    n_opt = len(options)
    fig, ax = plt.subplots(figsize=(12, 1.05 * n_opt + 3.0))     # 高度随选项数自适应
    ypos = np.arange(n_opt, dtype=float)[::-1]
    bh = 0.8 / len(YEARS)
    ...
    for i, y in enumerate(YEARS):
        vals = rates.loc[options, y].to_numpy(dtype=float)
        cnts = counts.loc[options, y].to_numpy(dtype=int) if show_counts else None
        offset = (i - (len(YEARS) - 1) / 2) * bh
        ax.barh(ypos + offset, vals, height=bh * 0.9, color=PALETTE[i],
                label=str(y), edgecolor="white")
        for j, v in enumerate(vals):
            if v <= 0:
                continue
            txt = f"{v:.1f}%" + (f"（{cnts[j]:,}人）" if show_counts else "")
            ax.text(v + vmax * 0.01, ypos[j] + offset, txt, va="center",
                    fontsize=7.5, color="#333333")
    ...
    ax.set_xlim(0, vmax * 1.32)
```

细节拆解：

- **水平而非垂直**：选项名长（"PyCharm Professional Edition"），垂直柱的 x 轴标签会旋转 90° 难读；水平布局让标签横排。**标签长 → 水平条形图**是选型的硬规则。
- **`bh = 0.8 / len(YEARS)` 组内条宽**：每个选项占一个 y 槽位，6 个年份条在槽内均分 0.8（留 0.2 作选项间空隙），`offset` 让 6 条以槽中心对称展开。`height=bh*0.9` 再留 10% 条间细缝。条数从 5 增到 6，条更细、标注更容易互相撞——这是"加一年"最容易踩的坑。
- **`figsize` 高度自适应**：`1.05 * n_opt + 3.0`——每选项约 1 英寸 + 标题脚注 3 英寸。Top 10 图自动比 Top 8 高。固定高度会让 10 个选项挤成一团。
- **双重标注**：`"26.5%（6,720人）"`。百分比可比、人数可查——第 6 章的"数字带样本量"纪律落到像素层面。`,{:,}` 千位分隔是可读性细节。
- **`xlim(0, vmax*1.32)`**：右侧留 32% 空间给标注文字。不预留的话，最长条（接近 vmax）的标注会溢出画布被裁掉。**条形图布局要先给标注留位再定坐标范围**，顺序反了就是"图能画出来但字看不见"。
- **零值不标注**（`v <= 0: continue`）：某年不存在的选项（如 2019 年尚未出现的 IDE、2023 年才拆出的用途选项）条长为 0，无字可标。反过来说，图上"某选项只有 3 条"本身就是"该题直到 2021 年才问"的元信息。
- **`labels` 可选参数**：热力图复用此函数时传中文标签；条形图直接用 `option_label` 去前缀（`ide.editor.VS Code` → `VS Code`）。列名到显示名的翻译集中在 `option_label` 一处。

## 8.4 交叉热力图：关联结构

```python
def plot_heatmap(tab, counts, row_order, title, xlabel, ylabel, fname,
                 n_by_year, miss_by_year, extra_note="") -> None:
    """交叉热力图，单元格标注行内占比与人数。"""
    tab = tab.reindex(index=row_order, fill_value=0.0)
    counts = counts.reindex(index=row_order, fill_value=0)
    vmax = max(35.0, float(tab.to_numpy().max()))
    fig, ax = plt.subplots(figsize=(12.5, 6.5))
    im = ax.imshow(tab.to_numpy(), cmap="YlGnBu", aspect="auto", vmin=0, vmax=vmax)
    ...
    for r in range(tab.shape[0]):
        for c in range(tab.shape[1]):
            p = float(tab.iat[r, c])
            n = int(counts.iat[r, c])
            color = "white" if p > vmax * 0.55 else "#222222"
            ax.text(c, r, f"{p:.1f}%\n({n:,})", ha="center", va="center", ...)
    ax.grid(False)
```

要点：

- **`imshow` 而非 seaborn**：依赖更少、且对标注循环的控制更直接。`aspect="auto"` 让单元格拉伸填满画布（否则 6×9 网格会缩成小方块）。
- **`vmax = max(35.0, data.max())`**：色标上限双保险。数据最大值很小时（全表都在 30% 以下），按最大值定 vmax 会让 25% 和 30% 看起来一个深一个浅、夸大差异；保底 35% 让色深有跨图可比的锚点。
- **双行标注 + 文字颜色随底色翻转**：`p > vmax*0.55` 时深色底配白字，否则黑字。阈值 0.55 是对 `YlGnBu` 色带中点附近对比度翻转点的经验估计——**文字可读性依赖底色亮度，定色标时就要考虑标注颜色**。
- **`ax.grid(False)`**：全局 rcParams 开了网格（`axes.grid=True`），热力图上网格线会切割单元格造成脏线，显式关掉。全局样式与局部需求冲突时，**局部显式覆盖并留注释**。
- **`reindex(row_order)`**：行序强制 "不足 1 年 → 11 年以上"（第 7 章有序轴问题在绘图层的最后一道防线）。

## 8.5 脚注：图表的口径声明

`_footnote` 是所有图的公共收尾：

```python
def _footnote(fig, n_by_year, miss_by_year, extra="") -> None:
    """在图底部添加脚注：数据来源 + 各年样本量/缺失率 + 口径说明。"""
    n_str = "；".join(
        f"{y} n={n_by_year[y]:,}（缺失 {miss_by_year[y]:.1f}%）" for y in YEARS if y in n_by_year
    )
    parts = [SOURCE_NOTE, f"各年有效样本：{n_str}。"]
    if extra:
        parts.append(extra)
    fig.text(0.01, 0.012, "  ".join(parts), fontsize=7.5, color="#555555",
             va="bottom", ha="left", wrap=True)
```

脚注三件套，缺一不可：

1. **数据来源与性质**（`SOURCE_NOTE`）："自报抽样数据，跨年比较请注意问卷措辞差异"——把第 6 章的统计自律写进每张图。
2. **各年有效样本与缺失率**：`2024 n=28,995（缺失 0.0%）` 逐年列出。读者据此自行判断哪年的差异可信。
3. **口径说明**（`extra`）：多选图附 `MULTI_NOTE`（"使用率为独立比例，合计可超 100%；排名排除 None"）；跨年措辞归并的图注明"已归并为同一口径"；Top N 图注明"仅保留前 8，其余并入其他"。

**字号 7.5pt、灰色、贴底**：信息要全但不能喧宾夺主。`fontsize=7.5` 配 `dpi=300` 输出，缩放到文档里依然可读。

配套的终端摘要让"图 + 数字"双通道输出：

```python
def _print_summary(num, fname, n_by_year, miss_by_year):
    ...
    print(f"[{num:02d}] {fname} 已生成；各年有效样本 {n_str}；缺失率 {lo:.1f}%–{hi:.1f}%")
```

跑批时无需打开图就能扫一眼缺失率量级，发现异常（如某年缺失飙到 60%）立即定位。

## 8.6 中文字体与输出设置

```python
def setup_matplotlib() -> None:
    """Windows 中文字体与全局样式。"""
    plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "Arial Unicode MS"]
    plt.rcParams["axes.unicode_minus"] = False
    plt.rcParams["figure.facecolor"] = "white"
    plt.rcParams["axes.grid"] = True
    plt.rcParams["grid.linestyle"] = "--"
    plt.rcParams["grid.alpha"] = 0.35
```

- **字体回退链**：微软雅黑 → 黑体 → Arial Unicode MS。中文标题/轴标签缺字体时 matplotlib 会画出方框（□），跨平台脚本必须有回退链（macOS 加 `PingFang SC`，Linux 加 `Noto Sans CJK SC`）。
- **`axes.unicode_minus=False`**：中文字体常缺 Unicode 负号（U+2212），负数标签会渲染成方框，改用 ASCII 连字符。
- **`matplotlib.use("Agg")` 在 import pyplot 之前**：无显示环境（CI、SSH）下也能出图，且避免 Windows 下打开多余 GUI 窗口。顺序不能反——use 在 pyplot 导入后无效。
- **`dpi=300` 落盘**：打印质量；`bbox_inches` 不用 tight 而靠 `subplots_adjust` 手工留白，保证每张图边距一致（脚注贴底不裁切）。

`CHARTS` 注册表 + `main` 参数路由：

每个 `chart_NN` 函数是"聚合 → 绘图 → 摘要"的三行组合，全部统计逻辑沉淀在 7 章的聚合函数里。新增图表 = 写一个 `chart_09` + 注册表加一行——**增不改动、改不扩散**。`python plot_survey.py 1 5` 支持增量出图，大表读取一次、多次出图共享。

**加一年要改四处**：`MASTER`（总表文件名）、`YEARS`、`PALETTE`（多补一色）、以及各 `chart_NN` 里的文案年份。2024 年数据入库时正是这么扩的，重跑后八张图的脚注自动变成六行样本量——**口径参数集中在配置区，是这个脚本最值钱的设计**。

## 8.8 本章要点

- 堆叠柱看结构（≤5 类），分组条形看比较（标签长必用水平），热力图看关联。
- 有序轴三道防线：聚合排序 → 调用方传 `order` → 绘图 `reindex`。
- 数字标注带人数、脚注带样本量与缺失率——口径声明是图的一部分。
- 标注省略（<4%）、色标保底（vmax≥35）、文字随底色翻转，都是"可读性工程"。
- 字体回退链、`Agg` 后端、`unicode_minus` 是 Windows 中文绘图三件套。
- 注册表模式让图表脚本可增量、可扩展。

### 参考答案

**8.1** 数据库 Top 12 堆叠：12 段 × 5 年，段宽大量 < 4%（长尾数据库 1%–3%），标注溢出、颜色超 5 色循环后混淆、各段合计超 100% 的语义在堆叠中根本不成立（堆叠要求构成互补，多选使用率不互补——堆叠后总高无意义，这也是为什么多选只能画分组条形）。三档画 12 组条形：损失构成合计 = 100% 的视觉锚点（"工作+兼顾+个人"结构一目了然的信息变成三条独立趋势），且年际结构转移（兼顾→个人）在堆叠图上一眼可见、在条形图上需要脑内相减。

**8.2** 给函数加参数 `sort_by: str | None = None`：`options` 未显式传入时按 `rates[sort_by].sort_values(ascending=False).index` 取序。默认不这么做：排序年份的选择会引入选择效应——按某一年排序时，该年的作答者构成（如 `ide.editor` 组 2023 年缺 55.4%、2024 年缺 56.9%，留下的是"更愿意回答工具题"的人群）会系统性影响排位，榜单本身成为"那一年口径"的产物；跨年均值排序（现状）对单年口径波动不敏感。若确实要展示"某年视角榜单"，应显式传参并在脚注注明排序依据。

**8.3** 段普遍 1%–4% 的数据（如小众框架组）：整段无数可读，读者只能靠颜色与图例粗估。替代方案：小于阈值的段改用引出线标注（`annotate` 带 arrowprops）或只标数值不标 "%"、放大字号上限；代价是引出线在密集段间会交叉成蛛网，工程复杂度高，一般只在"小段本身是分析重点"时值得做。更好的做法是回到选型层：小段多说明该图型不适合，换分组条形。

对照图 1 脚注（如 2019 n≈35,000、缺失 25.5%），一致则口径闭环。任何一张图的脚注都应能这样复算——这是"图表可审计"的最终检验。
