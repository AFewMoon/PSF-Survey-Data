# 问卷调查数据分析教材：清洗、对齐、统计与分析

以 PSF/JetBrains 年度 Python 开发者调查（2019–2023）的真实数据为贯穿案例，从原始 CSV 一步步做到跨年统计图表与分析报告。所有代码均取自本仓库的实际管线脚本，可复现、可扩展。

## 这套教材解决什么问题

新手学 pandas 清洗时，教程里的数据往往是干净的十几列小表；真实世界是 200 多列、五种年份结构、缺失率 0%–60%、同一概念五年换了四种措辞的原始数据。本教材以真实数据为主线，覆盖：

1. **数据认知**：拿到陌生数据先做什么（第 1 章）
2. **数据清洗**：缺失、空白、重复、列名、多选题、类型（第 2–3 章）
3. **跨年对齐**：列名对齐与取值对齐，含映射表设计（第 4–5 章）
4. **统计基础**：抽样、缺失机制、比例推断、卡方检验（第 6 章）
5. **统计实战**：单选/多选聚合、交叉分析（第 7 章）
6. **可视化**：堆叠柱、分组条形、热力图与统计图表规范（第 8 章）
7. **分析写作**：从数字到结论，结论的置信边界（第 9 章）

## 环境准备

- Python 3.12+（本项目使用 3.14+，教材代码兼容 3.12）
- 依赖：`pandas`、`numpy`、`matplotlib`
- 全部 CSV 为 UTF-8（原始文件带 BOM），读取一律 `encoding="utf-8-sig", keep_default_na=False`
- 缺失值约定：清洗后数据中缺失一律为**空字符串**，不是 `NaN`

## 如何使用本教材

- 每章正文都引用仓库中的真实代码段，建议对照脚本阅读。
- 每章末附**练习题与参考答案**。练习基于本仓库数据，可在仓库根目录直接运行。
- 大文件（原始/清洗/对齐 CSV 共约 600 MB），练习中尽量用 `usecols=` 按需读列。
